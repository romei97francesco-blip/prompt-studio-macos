# Contribuire

Le proposte sono benvenute tramite issue o pull request.

Prima di inviare una modifica:

1. non includere chiavi API o dati personali;
2. esegui `./Sorgenti/test.sh`;
3. esegui `./Sorgenti/compila.sh` su macOS;
4. descrivi il comportamento modificato e le verifiche eseguite.

Mantieni l'interfaccia semplice e in italiano. Le modifiche alle integrazioni API devono preservare la modalità locale e non devono salvare la chiave su disco.
