# Sicurezza

## Segnalazioni

Per segnalare una vulnerabilità, apri una segnalazione GitHub senza includere chiavi API, dati personali o contenuti riservati. Se la segnalazione richiede dettagli sensibili, chiedi prima al manutentore un canale privato.

## Chiavi API

- Non inserire chiavi nei file del progetto, nei commit, nelle segnalazioni o nelle schermate pubbliche.
- Crea una chiave OpenRouter dedicata all'app con il limite di spesa più basso adatto al tuo uso.
- Revoca immediatamente una chiave che sospetti sia stata esposta.

## Distribuzione

Le release pubblicate in questo repository possono essere firmate localmente ad hoc e non notarizzate da Apple. Verifica sempre che il file provenga dalla pagina Releases ufficiale del repository.
